API Documentation

PrismPay provides a RESTful API for programmatic access to payment infrastructure.

  • POST /api/v1/wallet/connect - Connect user wallet
  • POST /api/v1/payments/send - Initiate crypto payment
  • GET /api/v1/transactions/:id - Get transaction status
  • POST /api/v1/swap/quote - Get swap quote
  • POST /api/v1/merchant/request - Create payment request
